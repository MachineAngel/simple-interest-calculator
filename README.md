# simple-interest-calculator 
This Bash script calculates simple interest using the principal amount, the annual interest rate as a percentage, and the time period in years.

**Formula:** Simple interest = (principal × annual rate × time in years) ÷ 100

## How to run

```bash
bash simple-interest.sh
```

For example, a principal of 1,000 at an annual rate of 5% for 2 years earns 100 in simple interest.
